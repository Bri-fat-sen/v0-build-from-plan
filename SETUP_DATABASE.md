# AfriStream Database Setup Guide

## Option 1: Automatic Setup (Recommended)

1. Go to Supabase Dashboard: https://app.supabase.com
2. Select your AfriStream project
3. Go to **SQL Editor** in the left sidebar
4. Click **New Query**
5. Copy the entire contents of `/lib/supabase/schema.sql` from this project
6. Paste it into the SQL Editor
7. Click **Run** button
8. Wait for completion (all tables, indexes, RLS policies, and triggers will be created)

## Option 2: Using Supabase CLI

```bash
# Install Supabase CLI if not already installed
npm install -g @supabase/cli

# Link to your Supabase project
supabase link --project-ref YOUR_PROJECT_REF

# Push the schema
supabase push
```

## What Gets Created

✅ **Core Tables:**
- `profiles` - User profiles with tier and mode info
- `artists` - Artist profiles linked to users
- `albums` - Music albums
- `tracks` - Individual songs/tracks
- `movies` - Video content (movies, series, shorts)
- `podcasts` & `podcast_episodes` - Podcast content
- `playlists` - User playlists

✅ **User Activity Tables:**
- `likes` - User likes on any content
- `follows` - Artist/creator follows
- `play_history` - Track play history
- `watch_progress` - Video progress tracking
- `downloads` - Offline downloads

✅ **Platform Tables:**
- `notifications` - User notifications
- `analytics_daily` - Creator analytics

✅ **Triggers:**
- Auto-create user profile on signup
- Auto-update `updated_at` timestamps

✅ **Row Level Security (RLS):**
- All tables protected with RLS policies
- Users can only see their own private data
- Public content visible to all

## Verifying Setup

After running the schema SQL:

1. Go to Supabase Dashboard
2. Click **Table Editor** in left sidebar
3. You should see all tables listed
4. Click on `profiles`, `tracks`, `albums`, etc. to verify they exist

## Environment Variables

Once setup is complete, your `.env.local` should have these (they're auto-generated by v0):

```
NEXT_PUBLIC_SUPABASE_URL=your_url
NEXT_PUBLIC_SUPABASE_ANON_KEY=your_anon_key
SUPABASE_SERVICE_ROLE_KEY=your_service_role_key
```

## Testing the Connection

Run this to verify the backend is working:

```bash
# Test the auth flow
curl http://localhost:3000/api/auth/login

# Test content endpoints
curl http://localhost:3000/api/tracks
curl http://localhost:3000/api/albums
curl http://localhost:3000/api/movies
```

## Troubleshooting

**"RLS policy error":** Make sure you've confirmed your email in Supabase auth

**"Column does not exist":** The schema.sql didn't run completely - re-run it

**"Cannot insert because of RLS":** Your user ID doesn't match - sign in first
